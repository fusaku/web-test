# 日本住宅ローンシミュレーター (Japan Mortgage Simulator)

> 专为应对日本浮动利率（変動金利）、**40年超长贷款**、**5年规则（5年ルール）**、**125%规则（125%ルール）**与**未付利息（未払利息）**精确推演而设计的独立纯前端计算工具。

---

## 🌟 核心特性

1. **40 年超长房贷专项优化（默认 40 年，支持 1~50 年自由定制）**：
   - 针对越来越多购房者选择的 40 年（480 期）甚至 50 年超长房贷场景设计。
   - 输入框支持任意年限自由设定，并提供 25 年、30 年、35 年、40 年、45 年、50 年快捷筹码。
2. **严谨的“5年规则”与“125%规则”推演算法**：
   - **5年规则**：即使基准利率变动，每 5 年内实际扣款月供保持完全固定。
   - **125%规则**：第 6 年、第 11 年、第 16 年…等每个 5 年重算节点，新月供上限为上期月供的 1.25 倍（125%）。
3. **真实复现利息倒挂时的“未付利息（未払利息）”与期末一笔还清风险**：
   - 模拟极端加息场景下“每月利息 > 封顶月供”的倒挂现象。
   - 追踪本金暂停减少、未付利息累积挂账以及在第 40 年末必须一次性结清（一括返済）的真实风险。
4. **多场景加息预测**：
   - 🟢 全期平稳（基准利率不变）
   - 🟡 温和加息（每 5 年递增 0.25%）
   - 🟠 阶梯快速加息
   - 🔴 剧烈暴涨（压力测试，直观查看 125% 封顶与未付利息产生）
   - ⚙️ 自定义加息时间轴（自由设定各年份节点的利率）
5. **数据可视化与表格导出**：
   - Chart.js 绘制 40 年月供趋势、本金与利息构成堆叠图、本金残高与未付利息消减曲线。
   - 40 年按年汇总明细，支持展开查看任意年份的 12 个月逐月流水。
   - 支持一键导出带 UTF-8 BOM 的完整 CSV 还款计划表。
6. **100% 独立与轻量**：
   - 纯静态项目，零构建依赖，解压或克隆即可在任何 Web 服务器、GitHub Pages 或本地浏览器中双击直接运行。
   - 自带自适应深色/浅色模式引擎。

## ⚙️ 如何修改默认参数

### 1. 房贷计算器默认参数 (`config.js`)
你可以使用任何文本编辑器打开根目录下的 `config.js` 文件，修改以下字段保存后刷新页面即可生效：

```javascript
window.MORTGAGE_CONFIG = {
  defaultLoan: {
    principalMan: 3190,           // 你的贷款金额（单位：万円，如 3190万）
    termYears: 40,                // 你的贷款年限（年，如 40年）
    initialRate: 1.195,           // 你的贷款利率（%，如 1.195%）
    startYear: 2026,              // 放款起始年份（用于换算日历年月）
    startMonth: 11,               // 放款起始月份（如 2026年11月）
    repayMethod: 'equal_payment', // 元利均等返済 (等额本息)
    enable5YearRule: true,        // 5年规则
    enable125Rule: true           // 125%规则
  },
  quickChips: {
    principalList: [2000, 2500, 3000, 3190, 3500, 4000, 5000, 6000],
    termList: [20, 25, 30, 35, 40, 45, 50]
  },
  scenarios: {
    defaultScenario: 'mild',
    // 自定义加息节点（支持精确到具体年、具体月，如三菱UFJ银行的7月/1月调息）：
    customMilestones: [
      { year: 1, month: 3, rate: 1.345 },  // 第1年第3期 (2027年1月) 加息至 1.345%
      { year: 1, month: 9, rate: 1.495 },  // 第1年第9期 (2027年7月) 加息至 1.495%
      { year: 2, month: 3, rate: 1.645 },  // 第2年第3期 (2028年1月) 加息至 1.645%
      { year: 6, month: 1, rate: 1.950 }   // 第6年第1期 (2031年11月 5年规则重算) 升至 1.950%
    ]
  }
};
```

### 2. 税金计算器默认参数 (`tax/config.js`)
打开 `tax/config.js` 可自由配置年收入、横滨市社保、商业保险保费（生命险/地震险）、房贷余额及故乡税模式。

## 🚀 启动与使用

### 本地直接运行
直接在浏览器中双击打开根目录的 `index.html`（房贷模拟器）或 `tax/index.html`（税金计算器）即可离线使用全部功能。

### 本地轻量 HTTP 服务运行
```bash
# 在当前根目录下启动 HTTP 服务
python3 -m http.server 8000

# 访问地址：
# 房贷模拟器：http://localhost:8000/
# 税金计算器：http://localhost:8000/tax/
```

两工具之间顶部与底部导航已全面实现双向互通，并支持 URL 参数（如 `?mortgage=3190`）与深色/浅色主题状态自动同步。

## 🏦 日本各大银行规则参考

| 银行类型 | 代表银行 | 是否采用 5年/125% 规则 | 特点与影响 |
| :--- | :--- | :---: | :--- |
| **传统大型银行** | 三菱UFJ银行、三井住友银行、瑞穗银行 | **是** | 月供 5 年固定，每次上限 125%；加息过快可能产生未付利息与期末余款。 |
| **主流网络银行** | auじぶん銀行、住信SBIネット銀行 | **是** | 同样采用 5年/125% 规则，现金流平稳，但本金冲抵可能被推迟。 |
| **无规则银行** | 索尼银行 (Sony Bank)、PayPay银行 | **否** | 利率变动立即调整月供，保证到期精准结清为零，绝不产生未付利息，但家庭每月现金流波动较大。 |
