### 【神奈川県・横浜市标准专版】

> 专为在**神奈川县·横滨市（横浜市）**工作的正社员（会社員）量身打造的税金试算与节税推演工具。

## 🌟 横滨市特有税制与社保标准 (令和6年度)

本项目已精准内置神奈川县及横滨市特有的税法与社保规章：

### 1. 协会健保 (全国健康保険協会 神奈川支部)
* **健康保険料率**：**10.02%**（事业主与员工各半，个人负担 **5.01%**）
  *(区别于东京都的 9.98% / 4.99%)*
* **介護保険料率 (40~64岁)**：**1.60%**（全国统一下调，个人负担 **0.80%**）
* **厚生年金**：**18.30%**（个人负担 **9.15%**）
* **雇用保険**：**0.60%**（一般事业个人负担 **0.60%**）
* **社保综合费率**：
  * 未满 40 岁：$5.01\% + 9.15\% + 0.60\% = \mathbf{14.76\%}$
  * 40~64 岁：$5.01\% + 0.80\% + 9.15\% + 0.60\% = \mathbf{15.56\%}$

### 2. 横滨市个人住民税特有超过课税 (超過課税)
* **所得割税率**：
  * 横滨市民税：8.000%
  * 神奈川县民税：通常 2.000% + **「水源環境保全税」 0.025%** = 2.025%
  * **横滨市住民税所得割合计税率：10.025%**（高于全国常规的 10.0%）
* **均等割及森林环境税 (年额 6,200円)**：
  * 市民税均等割：3,900 円（含横浜市特有**「横浜みどり税」900円**）
  * 县民税均等割：1,300 円（含神奈川县**「水源環境保全税」300円**）
  * 国税森林环境税：1,000 円
  * **均等割年额合计：6,200 円**

## 🛡️ 商业保险料控除与实到手现金 (手取り) 计算

很多正社员年末在公司填写《保険料控除申告書》，但并不清楚商业保费对到手现金的实际拉动。本工具完整实现了新制税法四项细分：

### 1. 新制生命保险料控除 (平成24年以降合同)
三项独立阶梯测算，每项所得税最高 40,000 円、横滨住民税最高 28,000 円：
* ① **一般生命保険料** (死亡定期/终身险、学资险等)
* ② **介護医療保険料** (医疗险、癌症险、重疾险、介护险等)
* ③ **個人年金保険料** (商业养老定存年金)
* **控除封顶上限**：
  * 所得税合计上限：最高 **120,000 円** (4万 $\times$ 3)
  * 横滨住民税合计上限：法定封顶 **70,000 円**

### 2. 地震保险料控除
* 房屋火灾保单附带的地震险保费：
  * 所得税：全额扣除，最高 **50,000 円**
  * 横滨住民税：保费的 50%，最高 **25,000 円**

### 3. 到手收入 (手取り) 的双层呈现
* **法定税后手取り**：$\text{年收} - \text{社保} - \text{所得税} - \text{横滨住民税}$（已将保险控除带来的减税/退税红利计算在内）。
* **自由现金手取り**：$\text{法定税后手取り} - \text{商业保险总保费支出}$（扣除自己真金白银交给保险公司的保费后的纯净现金）。
* **商业保险节税收益看板**：清晰展示通过年末调整从国税和横滨市税局省下的税金金额（通常每年为纳税人直接省下 ¥20,000 ~ ¥40,000+）！

## 🏡 住宅借入金等特別控除 (房贷减税) 深度拆解

* **第 1 顺位：当年所得税直接抵扣**
  * 理论最大减税额 = $\min(\text{年末贷款余额}, \text{环保类别限额}) \times \text{控除率 (0.7\%)}$
  * 当年算出所得税全额冲减，抵扣完即止。
* **第 2 顺位：翌年横滨住民税转嫁抵扣**
  * 若所得税不够扣，残余部分转入翌年 6 月起横滨住民税（所得割）冲抵。
  * **法定转嫁上限**：现行制度（2022年起入居）为前一年课税所得的 **5%**，且每年最高不超过 **97,500 円**！
* **第 3 顺位：未用尽浪费失效（控除しきれない枠）**
  * 提供三段式彩色进度条，一眼看清你的房贷减税是否全额拿满，还是因撞上 97,500 円上限而产生溢出浪费。

## ⚡ 杀手级功能：One-Stop 特例 vs 確定申告 避坑指南

| 维度 | ワンストップ特例 (One-Stop特例 · 推荐) | 確定申告 (Kakutei Shinkoku) |
| :--- | :--- | :--- |
| **适用人群** | 自治体 $\le 5$ 个，且由公司年末调整（**买房第2年起强烈推荐**） | **买房第1年必须办理**，或自治体 $> 5$ 个，或年收超2000万 |
| **故乡税扣税方式** | 全部从**翌年横滨住民税**中全额抵扣，所得税完全不扣 | 走所得税**寄附金控除**，直接扣减所得税课税所得 |
| **对房贷减税的影响** | **零影响**。所得税额保持完整，房贷减税可 100% 优先在所得税中吃满 | **有侵蚀风险！** 所得税因课税基数减少而下降，房贷减税被挤入住民税，若撞上 97,500 円上限，**多出来的房贷减税直接蒸发！** |
| **本工具智能诊断** | 自动对比两种方式下的减税到手金额与损失差额，并计算出確定申告下的“绝对安全故乡税上限”！ |

## 📄 源泉徴収票（日本年末调整税单）字段对照表

测算结果完全对齐日本源泉征收票栏目：
* ① **支払金額**（税前年收）
* ② **給与所得控除後の金額**（扣除给与控除后的所得）
* ③ **社会保険料等の金額**（神奈川支部社保）
* ④ **生命保険料の控除額**（新制一般+医疗+年金）
* ⑤ **地震保険料の控除額**
* ⑥ **所得控除の額の合計額**（社保 + 基础控除 + 保险控除 + 抚养/配偶）
* ⑦ **住宅借入金等特別控除の額**（房贷所得税抵扣）
* ⑧ **源泉徴収税額**（最终实缴所得税，含 2.1% 振兴特别税）

## ⚙️ 如何修改默认参数 (`tax/config.js`)

你可以用任意文本编辑器打开 `tax/config.js`，保存后刷新页面即可直接生效：

```javascript
window.TAX_CONFIG = {
  region: {
    prefecture: 'yokohama'        // 默认按神奈川县横滨市计算
  },
  defaultProfile: {
    grossAnnualIncomeMan: 700,    // 你的年收入（单位：万円，如 700万）
    ageOver40: false,             // 是否满 40 岁（40岁以上加征介护保险 0.80%）
    socialInsuranceMode: 'auto',  // 'auto' 自动按神奈川支部标准估算 或 'manual' 手动输入
    spouseStatus: 'none',         // 配偶状况：'none' / 'dependent' / 'part_time'
    dependents16to18: 0,          // 一般抚养亲属人数
    dependents19to22: 0,          // 特定抚养亲属人数 (大学生)
    idecoAnnualMan: 0             // iDeCo 年缴金额 (万円)
  },
  defaultInsuranceDeductions: {
    lifeInsuranceGeneralMan: 8,   // 一般生命保险料年缴额 (8万拿满控除4万/2.8万)
    lifeInsuranceMedicalMan: 8,   // 医疗介护保险料年缴额 (8万拿满控除4万/2.8万)
    lifeInsuranceAnnuityMan: 0,   // 个人年金保险料年缴额
    earthquakeInsuranceMan: 1.5   // 地震保险料年缴额 (1.5万)
  },
  defaultMortgage: {
    enabled: true,                // 是否开启房贷减税
    balanceMan: 3190,             // 年末贷款余额 (万円，如 3190万)
    deductionRate: 0.7,           // 控除率 (现行 0.7%)
    houseType: 'energy_saving',   // 房屋环保等级 (省能标准适配 3000~4000万)
    moveInYear: 2024              // 入居年份
  },
  defaultFurusato: {
    preferredMethod: 'onestop',   // 申报模式：'onestop' 或 'shinkoku'
    plannedDonationMan: 0         // 计划购买金额 (0 为系统推荐上限)
  }
};
```

## 🚀 本地运行与访问

1. **直接打开**：在访达（Finder）或文件管理器中直接双击打开 `tax/index.html`。
2. **本地静态服务**：
   ```bash
   python3 -m http.server 8000
   ```
   浏览器访问：`http://localhost:8000/tax/`。
3. **工具联动**：顶部与底部均支持一键前往 [40年房贷模拟器](../) 并自动同步房贷金额。
